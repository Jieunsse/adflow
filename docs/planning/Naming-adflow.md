# 이름 다시 짓기 초안

작성일: 2026-11-11 · 상태: 초안 (확정 전)
근거 문서: 디자인 설계(`Design-adflow.md` 4.2의 0번 단계), 법·행정(`docs/company/06-legal-admin.md` 2절)

## 1. 왜 다시 짓는가

| 이유 | 내용 |
|---|---|
| 같은 이름이 이미 많습니다 | 웹 검색 결과 "AdFlow"는 여러 광고 제품이 쓰고 있습니다. 소셜 광고 소재를 자동으로 만드는 Adflow.io가 있고, 미국에는 같은 이름의 퍼포먼스 마케팅 대행사가 있습니다. 둘 다 우리와 같은 분야입니다 |
| 국내 도메인도 이미 쓰입니다 | `adflow.co.kr`은 "Adflow"라는 이름의 다른 등록자가 가지고 있습니다 |
| 상표 등록이 어렵습니다 | "광고(Ad)+흐름(Flow)"은 서비스 내용을 그대로 설명하는 말입니다. 이런 이름은 상표 등록에서 거절되기 쉽습니다 (변리사 확인 필요) |

## 2. 이름 기준

| 기준 | 이유 | 상태 |
|---|---|---|
| 회사 이름과 제품 이름을 하나로 씁니다 | 우리는 자기 도구로 일하는 대행사입니다. 이름이 둘이면 알리는 비용이 두 배가 됩니다 | 권장 |
| 한 번 듣고 받아 적을 수 있습니다 | 상담과 소개는 전화와 카카오톡으로 이루어집니다 | 권장 |
| 한글로 3음절 안팎입니다 | 대표가 다른 대표에게 말로 소개하기 쉬워야 합니다 | 권장 |
| 브랜드 핵심(실험, 근거, 쌓임) 중 하나가 들립니다 | `Design-adflow.md` 4.3 | 권장 |
| "AI", "광고", "마케팅" 같은 설명하는 말을 넣지 않습니다 | 상표 등록이 어렵고, 같은 분야에 비슷한 이름이 많습니다 | 권장 |
| 광고, 소프트웨어 분야에 같거나 비슷한 이름이 없습니다 | 법·행정 문서 2절 | 확정 |

## 3. 후보

빠른 확인은 웹 검색과 도메인 조회(2026-11-11)만 한 것입니다. 상표 검색은 아직 하지 않았습니다.

| 후보 | 뜻 | 좋은 점 | 약한 점 | 빠른 확인 |
|---|---|---|---|---|
| **한끗** | "한 끗 차이". 한 가지만 바꿔 차이를 보는 실험 방식 | 실험 방식이 이름에 그대로 들어 있습니다. 우리말이라 대표 고객에게 바로 통합니다 | 영어로 적기 어렵습니다 (Hankkeut) | 같은 이름의 광고 회사는 찾지 못함. `hankkeut.com`은 이미 등록됨 |
| **넥스트컷** (Nextcut) | 다음 컷. 광고에서 "컷"은 소재 한 장을 뜻합니다 | 비전 "다음 광고를 더 낫게"가 들립니다. 영어와 한글 모두 쉽습니다 | 영어권에서는 "다음 편집"으로도 읽힙니다 | 같은 이름의 광고 회사는 찾지 못함. `nextcut.kr`은 비어 있음, `nextcut.co`는 이미 등록됨 |
| **켜켜** | "켜켜이 쌓인다" | 쌓이는 지식이라는 약속이 들립니다 | 영어로 적기 어렵고, 처음 들으면 뜻을 바로 알기 어렵습니다 | `kyeokyeo.com`은 비어 있음 |
| **케언** (Cairn) | 산길에 돌을 쌓아 길을 표시하는 돌무더기 | 쌓임과 다음 길을 함께 담습니다 | 한국에서는 낯선 단어입니다. 인플루언서 마케팅 소프트웨어 eCairn과 비슷합니다 | `cairn.co.kr`은 비어 있음 |
| 프루프라인 (Proofline) | 근거의 줄 | 근거가 있다는 성격이 들립니다 | "Proof"로 시작하는 마케팅 분석 도구가 많습니다 | `proofline.co`는 이미 등록됨 |
| ~~스트라타~~ (Strata) | 지층 | | 같은 이름의 광고 기술 회사가 있습니다 (현재 Comcast FreeWheel 소속) | 후보에서 뺌 |

## 4. 권장

1순위는 **한끗**, 2순위는 **넥스트컷**입니다 (권장).

- **갱신 (2026-11-11).** 사용자 판단으로 "한끗"은 이미 누군가 쓰고 있을 가능성이 높아 그대로 쓰지 않습니다. 두 후보를 섞은 2차 후보는 6절에 있습니다.

- 한끗은 우리 실험 방식(바꾸는 요소는 하나)을 가장 정확하게 말합니다. 첫 고객이 한국의 작은 브랜드 대표라서, 우리말 이름의 약점(영어 표기)이 크지 않습니다.
- 넥스트컷은 영어 표기와 도메인이 쉽습니다. 나중에 해외 고객까지 생각한다면 더 낫습니다.

## 5. 다음 단계

1. 사용자가 후보 2~3개를 고릅니다. 다른 방향의 후보를 더 원하면 2절 기준으로 다시 만듭니다.
2. 고른 후보를 특허청 키프리스에서 검색합니다. 범위는 9류(소프트웨어), 35류(광고 대행), 42류(소프트웨어 서비스)입니다.
3. 도메인(`.com`, `.kr`, `.co.kr`)과 인스타그램, 카카오톡 채널 이름이 비어 있는지 확인합니다.
4. 걸리는 것이 없으면 이름을 확정하고, 디자인 설계 4.2의 로고 단계로 넘어갑니다.
5. 이름이 확정되면 기획서, 정책서, 회사 설계 문서의 "AdFlow"를 바꿉니다. 코드 안의 이름은 따로 정합니다.

## 6. 2차 후보: 한끗과 넥스트컷 섞기

두 이름에서 하나씩 가져왔습니다. 한끗에서는 "끗(작은 차이)"을, 넥스트컷에서는 "컷(소재 한 장)"과 "다음"을 가져왔습니다.
"끗"은 영어로 적으면 Kkut이고, 소리가 영어 cut(컷)과 비슷합니다. 그래서 한 글자에 두 이름의 뜻이 함께 들어갑니다.

| 후보 | 뜻 | 좋은 점 | 약한 점 | 빠른 확인 (2026-11-11) |
|---|---|---|---|---|
| **끗랩** (KKUT LAB) | 끗 차이를 찾는 실험실 | "브랜드의 광고 실험실"이라는 콘셉트가 이름에 그대로 들어 있습니다. "랩"이 붙어 끗 한 글자보다 상표로 구별되기 쉽습니다 | 두 단어를 붙인 이름이라 "끗"만큼 짧지는 않습니다 | 같은 이름의 회사는 찾지 못함. `kkutlab.com`, `kkutlab.kr` 모두 비어 있음 |
| **끗** (KKUT) | 끗 차이. 영어로 읽으면 cut(소재 한 장) | 한 글자라 가장 짧고 기억하기 쉽습니다. 한글과 영어 양쪽에서 뜻이 통합니다 | 한 글자 이름은 상표로 구별되기 어려울 수 있습니다. `kkut.com`은 이미 등록돼 있습니다 | 같은 이름의 회사는 찾지 못함. `kkut.kr`, `kkut.co.kr`은 비어 있음 |
| **넥스트끗** (NEXTKKUT) | 다음 끗. 다음 광고에서 찾을 작은 차이 | 비전 "다음 광고를 더 낫게"와 실험 방식이 모두 들어갑니다 | 영어와 한글을 섞어 처음 들으면 받아 적기 어렵습니다 | `nextkkut.com`은 비어 있음 |
| ~~한컷~~ (HANCUT) | 한끗의 소리와 컷을 합침 | | `hancut.com`, `hancut.kr` 모두 이미 쓰이고, `hancut.kr`은 운영 중인 사이트입니다 | 후보에서 뺌 |
| ~~원끗~~ (ONEKKUT) | 한 끗을 영어 one으로 바꿈 | | `onekkut.com`이 이미 등록돼 있습니다 | 후보에서 뺌 |

### 6.1 권장

1순위는 **끗랩**입니다 (권장).

- 회사 콘셉트("광고 실험실")를 그대로 말합니다.
- `.com`과 `.kr` 도메인이 모두 비어 있습니다.
- 대표에게 "끗랩이에요. 끗 차이를 찾는 광고 실험실이요."처럼 한 문장으로 소개할 수 있습니다.

2순위는 **끗**입니다. 더 짧지만, 한 글자 이름이 상표로 등록될 수 있는지 먼저 변리사에게 확인해야 합니다.
