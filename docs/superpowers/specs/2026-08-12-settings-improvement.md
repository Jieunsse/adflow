# 설정 페이지 개선 명세

> 2026-08-12 · 구현 전 화면 명세

## 목표

설정이 실제로 적용되는 범위와 화면을 일치시키고, 개인·워크스페이스·관리자 설정을 빠르게 찾게 한다.

- 작동하지 않는 알림을 선택 가능한 설정처럼 보이지 않게 한다.
- Pixel 선택 전에는 유효하지 않은 코드를 복사할 수 없게 한다.
- 민감한 자격증명은 팀장만 바꾸되, 팀원도 현재 준비 상태는 알 수 있게 한다.

## 범위 밖

- 브라우저 푸시·이메일 알림, Pixel 이벤트 수신의 앱 내 자동 검증
- Meta 앱·Gemini 키의 저장 방식이나 권한 정책 변경
- 새 API, 새 저장소, 새 라우트

## 화면 구조

기존 `/settings` 단일 페이지와 `/settings#measurement` 딥링크를 유지한다. 헤더 바로 아래에 앵커형 카테고리 내비게이션을 둔다. 데스크톱에서는 한 줄, 좁은 화면에서는 줄바꿈한다. 별도 탭 라우트나 사이드바는 만들지 않는다.

```
설정
내 환경과 워크스페이스 운영 설정을 관리해요.

[ 설정 현황 ]
  Pixel 선택 · Meta 앱 · AI 기능

[ 내 환경 ] [ 워크스페이스 ] [ 관리자 ]

내 환경
  앱 내 알림
  계정
  데이터 관리

워크스페이스
  전환 측정

관리자 (팀장만 조작 가능)
  Meta 앱 연결 · Gemini API 키
```

- 앵커는 `#environment`, `#measurement`, `#credentials`를 사용한다. `#measurement`는 기존 대시보드 링크 호환을 위해 유지한다.
- 각 앵커는 포커스 시 섹션 제목이 보이도록 sticky 헤더 높이를 고려해 스크롤한다.
- 카드·칩·버튼은 기존 `Card`, `Chip`, `Button`과 디자인 시스템 토큰을 재사용한다. 새 공용 UI는 만들지 않는다.

## 설정 현황

상단에 세 개의 작은 상태 항목을 둔다. 현황은 완료율이나 진행률로 합산하지 않는다. Pixel 설치와 Meta 테스트를 앱이 검증할 수 없기 때문이다.

| 항목 | 상태 판정 | 팀장 행동 | 팀원 표시 |
|---|---|---|---|
| 전환 측정 Pixel | 선택됨 / 선택 필요 | `연결에서 선택` 또는 `전환 측정으로 이동` | 상태와 `팀장에게 요청` 안내 |
| Meta 앱 | 연결됨 / 연결 필요 | `자격증명으로 이동` | 상태만 |
| AI 기능 | 사용 가능 / 설정 필요 | `자격증명으로 이동` | 상태만 |

- `연결됨`, `선택됨`, `사용 가능`은 칩 텍스트로 명시한다. 색만으로 상태를 전달하지 않는다.
- 팀원에게는 App ID, API 키 출처, 마지막 변경자·시각, 변경 버튼을 보이지 않는다.
- 설정하지 않은 팀원용 항목의 안내 문구는 `팀장이 설정하면 사용할 수 있어요.`로 통일한다. 실제 요청 생성 기능은 만들지 않는다.

## 내 환경

### 앱 내 알림

제목을 `알림`에서 `앱 내 알림`으로 바꾸고, 설명을 `AdFlow 안의 알림 목록에 표시해요. 이 기기에만 저장돼요.`로 바꾼다.

작동하는 설정은 네 개만 활성 토글로 제공한다.

1. 광고가 게재됐을 때 (`launch`)
2. 광고 상태가 바뀌었을 때 — 승인·거부·이슈 (`adStatus`)
3. AI 최적화 제안이 있을 때 (`opt`)
4. 자동 재게재를 준비할 수 있을 때 (`autoRelaunch`)

`성과가 갑자기 변동했을 때`와 `주간 성과 요약`은 토글을 비활성 상태로 두고 `준비 중`을 함께 표시한다.

- 비활성 옵션은 값을 변경하거나 저장하지 않는다. 저장된 과거 값도 화면에서 활성화된 것처럼 표시하지 않는다.
- 브라우저 푸시나 이메일 수신을 암시하는 문구·권한 요청을 추가하지 않는다.

### 계정과 데이터 관리

`계정`에는 온보딩 다시 보기와 로그아웃만 둔다. `데이터 관리`는 별도 섹션의 맨 아래에 배치하고, 로컬 데이터 삭제만 경고 스타일로 둔다.

- 삭제 설명: `이 기기의 소재 라이브러리와 작성 중인 광고 입력값을 지워요. Meta 광고와 워크스페이스 데이터는 지워지지 않아요.`
- 확인 모달은 삭제 대상과 복구 불가를 다시 알리고, 기본 포커스는 `취소`에 둔다.
- 온보딩 다시 보기·로그아웃은 일반 보조 버튼을 유지한다.

## 워크스페이스 — 전환 측정

전환 측정은 Pixel이 선택된 뒤에만 코드를 제공한다. 현재의 `<픽셀 ID>` 대체값을 포함한 코드와 복사 버튼은 제거한다.

### Pixel 미선택

- 상태: `선택 필요`
- 본문: `전환 매출과 ROAS를 보려면 연결에서 사용할 Pixel을 먼저 선택해요.`
- 팀장 행동: `연결에서 Pixel 선택`
- 팀원: 선택 권한이 없다는 안내만 표시한다.
- 코드 카드와 복사 버튼은 렌더하지 않는다.

### Pixel 선택됨

선택한 Pixel 이름·ID를 먼저 보이고, 아래의 순서 안내와 코드 카드를 노출한다.

1. 모든 페이지에 기본 코드를 붙여요.
2. 주문 완료 페이지에 구매 이벤트 코드를 붙여요.
3. Meta 이벤트 관리자의 `테스트 이벤트`에서 수신을 확인해요.

- 세 번째 단계는 외부 Meta 이벤트 관리자로 이동하는 링크와 확인 방법만 제공한다. 완료 체크, 완료 뱃지, 영구 저장은 만들지 않는다.
- 코드 복사는 선택된 실제 Pixel ID로 만든 경우에만 가능하다.
- 구매 이벤트의 금액·통화는 예시 값임을 코드 위에서 분명히 알린다.

## 관리자 — 자격증명

팀장에게만 Meta 앱 연결과 Gemini API 키 카드를 보여주고 변경을 허용한다. 팀원은 상단 설정 현황에서 준비 상태만 본다.

- Meta 앱: 연결 상태, App ID, 마지막 변경 이력, `자격증명 교체`를 기존 설치 마법사로 연결한다.
- Gemini API 키: 설정 상태와 출처 설명, 키 설정·교체만 제공한다. 키는 재표시하지 않는다.
- 둘러보기 모드는 현재처럼 읽기 전용이다. 상태는 보여 주되 저장 버튼은 동작하지 않는다.

## 구현 경계

영향 파일은 우선 아래 세 곳으로 한정한다.

- `apps/web/app/(workspace)/settings/page.tsx`: 화면 구조·문구·권한별 표시·Pixel 미선택 차단
- `apps/web/src/shared/lib/notifications.ts`: 기존 `autoRelaunch` 설정을 화면에 연결. 준비 중 설정은 화면에서 변경되지 않게 유지
- 필요 시 기존 `@shared/ui` 컴포넌트의 지원 범위 내 스타일 조정

기존 `/api/workspace/meta-target`, `/api/install/meta-app`, `/api/settings/gemini-key`를 재사용한다. 현황과 각 카드는 같은 상태를 공유해 중복 요청을 만들지 않는다.

## 완료 기준

- [ ] Pixel 미선택 상태에서 코드와 복사 버튼이 보이지 않는다.
- [ ] 실제 생성되는 네 종류의 앱 내 알림을 각각 켜고 끌 수 있다.
- [ ] 성과 변동·주간 요약은 `준비 중`이며 변경할 수 없다.
- [ ] 팀원은 자격증명의 상태만 보고 값·변경 동작은 볼 수 없다.
- [ ] 팀장은 기존 Meta 앱·Gemini 키 변경 동작을 계속 사용할 수 있다.
- [ ] `/settings#measurement`에서 전환 측정 섹션으로 이동한다.
- [ ] 로컬 데이터 삭제의 대상과 Meta/워크스페이스에 미치는 영향이 구분돼 있다.
